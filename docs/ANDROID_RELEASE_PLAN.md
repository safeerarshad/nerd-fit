# Android build and release plan

Development ID: `dev.nerdfit.preview`. **Permanent application ID selection is a release blocker.** Never upload the placeholder. No store publication is authorized by this plan.

## Local toolchain

Node24 LTS, npm lockfile, JDK17, Android SDK36 and the Gradle wrapper generated by the compatible Expo57 prebuild. No paid cloud build required. Installed tool versions are recorded in ARCHITECTURE; actual prebuild/compile results belong in BUILD_STATE.

Planned command contract: `npm ci`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run prebuild:android`, `npm run android`, `npm run build:apk`, `npm run build:aab`. These commands become documented as runnable only after scaffold supplies and verifies them. Local Gradle tasks are `app:assembleDebug` and `app:bundleRelease`; a standalone internal APK also needs its bundled JavaScript. Do not mistake a Metro-dependent debug APK for an offline release artifact.

Native Gradle wrapper/project and config plugins are versioned; local.properties, signing properties, keystores, tokens and build caches are not. Native changes must survive controlled prebuild. Configure signing through environment/ignored local properties and fail closed for store builds without a real identity; do not reuse Expo's default debug signing for release.

## Release checklist

- [ ] Permanent ID approved; versionCode/versionName selected.
- [ ] Current Google Play target SDK policy rechecked against official Android/Play documentation.
- [ ] Original icon, adaptive/monochrome icon, splash and name verified.
- [ ] APK installed and tested on real Android, including offline restart and process death.
- [ ] Compact/large/foldable/tablet, keyboard/font/navigation modes exercised.
- [ ] Unit/integration/simulation/E2E/performance gates pass with recorded evidence.
- [ ] Dependency licenses and food-pack provenance/attribution included.
- [ ] Privacy policy, Data Safety, Health Connect declarations and AI disclosures match traffic.
- [ ] Camera/notification/Health Connect permissions limited and denied-state flows pass.
- [ ] Codex Security scan reviewed; unresolved release blockers documented.
- [ ] User-controlled release signing outside Git; debug signing rejected.
- [ ] AAB built, bundletool validation run and installable splits smoke-tested.
- [ ] Final store assets and human approval before any publication.
